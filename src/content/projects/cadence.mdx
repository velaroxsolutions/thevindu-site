## The problem

Posting consistently across platforms means either paying for a scheduler or doing it by hand
at the moment the post needs to go out. I was doing it by hand, at midnight.

## What I built

A composer that targets any mix of connected accounts, with per-platform variants, threads,
first comments, images and video. A queue, a calendar with drag-to-reschedule, and recurring
posts. An Insights view with real engagement, follower growth, a best-time heatmap and
tracked links.

It ships as a web app and as a self-contained desktop app: Tauri wraps the UI, and the FastAPI
server rides along as a sidecar.

## What I learned

Every platform’s docs are slightly wrong, or slightly out of date. I stopped writing any
integration until I’d checked the current API first. It caught a problem almost every time.

Retries are where double-posts come from. The failures dashboard now retries only the targets
that didn’t succeed.

## Next

Instagram, Facebook, TikTok, YouTube and Pinterest are waiting on platform app approvals, not
code. Their adapters slot into the same pattern.
